How to Update This Dashboard

Weekly (Every Monday)
1. Open the KPI Scorecard tab
2. Click the Current cell for ATTR, PM Compliance, and Kooner Adoption
3. Type the latest value from FleetIQ
4. Update the status pill if it has changed
5. Save and share with leadership by Tuesday
Monthly (By the 5th)
1. Receive Finance actuals (Margin vs. Plan, Labor Cost %)
2. Pull SLA performance and NPS from respective sources
3. Update all Current values in the KPI Scorecard
4. Update KR statuses on the OKR Progress tab
5. Refresh the headline stats on the Overview tab
Quarterly (March · June · Sept · Dec)
1. Update all 36 KR statuses and progress values
2. Update strategy-specific KPIs (markets analyzed, recommendations actioned, etc.)
3. Mark completed one-time deliverables as Done
4. Update the Overview stat cards (On Track / At Risk / Completed counts)
5. Distribute the refreshed dashboard before the quarterly review meeting
Ad Hoc (When a milestone lands)
1. Navigate to the relevant pillar on the Overview tab
2. Change the status pill for the completed KR to Completed
3. Update the progress to 100%
4. Increment the Completed count on the Overview stat cards
5. Note the completion date in the Excel source file
